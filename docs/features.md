# Food Delivery Application — Complete Feature Requirements

## 1. Customer / User

* Registration, login, logout, OTP/email verification, forgot/reset/change password
* Social login, session/device management, account activation/deactivation/deletion
* Profile: name, photo, phone, email, preferences, language, privacy settings
* Location detection, GPS, manual location, map selection, city/locality detection
* Address management: add/edit/delete, Home/Work/College/Other, default address, landmark, coordinates, delivery instructions
* Restaurant discovery: nearby, popular, trending, top-rated, new, recommended, recently viewed
* Food/cuisine/category discovery
* Search by restaurant, food, dish, cuisine, brand and location
* Search suggestions, autocomplete, recent/popular searches, typo correction, voice search
* Filters: rating, price, distance, delivery time, cuisine, veg/non-veg, vegan, healthy, offers, open now, fast/free delivery, popularity
* Sorting: relevance, rating, distance, delivery time, price, popularity
* Restaurant details: images, name, rating, reviews, cuisine, price, address, distance, timings, status, delivery information
* Restaurant sections: overview, menu, reviews, photos, about
* Menu categories and food-item details
* Food images, descriptions, prices, discounts, availability, bestseller/recommended tags
* Ingredients, allergens, nutritional information
* Food customization: size, quantity, add-ons, toppings, ingredients, spice level, special instructions
* Cart: add/remove/update quantity, customization, item availability, price updates, clear cart
* Cart calculations: subtotal, taxes, packaging fee, delivery fee, platform fee, discounts, surge, tip, total
* Coupons: code, automatic offers, first-order offers, user-specific offers, minimum order, maximum discount, expiry, usage limits
* Checkout: address, contact, delivery instructions, coupon, tip, payment method, order summary
* Payments: UPI, cards, net banking, wallets, COD, gift/promotional balance
* Payment status: pending, success, failed, retry, transaction ID, invoice, refund, partial refund
* Order placement, confirmation, modification/cancellation where permitted
* Order lifecycle: placed, confirmed, accepted, preparing, ready, assigned, picked up, out for delivery, delivered, cancelled, failed, refunded
* Live order tracking, ETA, delivery status, map, delivery partner details/location
* Customer-delivery partner communication: call/chat/contact masking
* Order history, order details, invoices, payment history
* Reorder previous orders with availability/price validation
* Favorites/saved restaurants and food
* Ratings for food, restaurant, delivery and overall experience
* Reviews, photos, edit/delete/report review, helpful votes, restaurant responses
* Notifications: order, payment, delivery, account, offers and promotions
* Notification preferences for push/email/SMS
* Customer support: FAQ, chatbot, live support, tickets, complaints, escalation, refund requests
* Complaint categories: missing/wrong item, late delivery, quality, payment, refund, restaurant, delivery partner, coupon, account
* Accessibility, multilingual interface and user-friendly UI
